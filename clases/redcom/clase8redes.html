Clase 8

División de Subredes con Longitud Variable (VLSM)

Aprende a diseñar esquemas de direccionamiento IP altamente eficientes que se adapten a las necesidades reales de hosts en cada subred, reduciendo el desperdicio de direcciones IP al mínimo.

Objetivos de la Clase
  • Diferenciar entre la división de subredes tradicional (FLSM) y de longitud variable (VLSM).
  • Comprender la matemática y las fórmulas detrás del cálculo de máscaras de subred de longitud variable.
  • Seguir un proceso paso a paso para resolver cualquier problema de direccionamiento estructurado.
  • Utilizar el simulador interactivo para calcular y validar direccionamientos IP en escenarios reales.

1. Introducción y Conceptos Clave

En el subnetting clásico o FLSM (Fixed Length Subnet Mask), todas las subredes creadas tienen el mismo tamaño y la misma máscara de subred. Si bien este enfoque es simple, genera un gran desperdicio de direcciones IP cuando los segmentos de red tienen requerimientos de hosts muy desiguales (por ejemplo, una subred de producción con 100 hosts y un enlace serial WAN que solo requiere 2 IPs utilizables).

FLSM
Máscara Fija

Todas las subredes comparten idéntica máscara (ej. `/26`). Un enlace WAN con solo 2 hosts desperdicia 60 IPs en una subred diseñada para 62 hosts.

VLSM
Máscara Variable

Cada subred recibe una máscara adaptada a su tamaño de host requerido (ej. `/25` para 100 hosts, `/30` para enlaces WAN). Optimización máxima del espacio de direccionamiento.

¿Por qué usar VLSM?

VLSM permite subdividir una subred en partes más pequeñas de forma jerárquica. Esto reduce el tamaño de las tablas de enrutamiento mediante la **sumarización de rutas** y previene el agotamiento prematuro de direcciones IPv4 públicas y privadas.

2. Proceso de Cálculo en Pasos

Para realizar la división de subredes mediante VLSM correctamente, sigue esta metodología estructurada:

1
Ordenar los Requerimientos

Ordena las subredes solicitadas de mayor a menor según la cantidad de hosts requeridos. Esto asegura que los bloques de direcciones más grandes se asignen primero, previniendo solapamientos.

2
Calcular la cantidad de bits de Host ($h$)

Encuentra el menor número entero $h$ de bits de host de modo que satisfaga la fórmula fundamental:

2h - 2 ≥ Hosts Requeridos

El "-2" representa la dirección de red y la dirección de broadcast, las cuales no pueden asignarse a un host de la red.

3
Determinar la Nueva Máscara de Subred

Resta la cantidad de bits de host ($h$) a los 32 bits totales de la dirección IPv4 para obtener el prefijo CIDR de la subred: Prefijo = 32 - h.

4
Calcular los Rango de Direcciones

Define el segmento:

  • Dirección de Red: La primera IP del bloque actual.
  • Primera IP Utilizable: Dirección de Red + 1.
  • Última IP Utilizable: Dirección de Red + (Tamaño del bloque - 2).
  • Dirección de Broadcast: Dirección de Red + (Tamaño del bloque - 1).
5
Asignar la Siguiente IP de Red

La dirección de red para la siguiente subred es simplemente la Dirección de Broadcast de la subred actual + 1. Repite el proceso para todas las subredes.

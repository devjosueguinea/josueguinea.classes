1. De la Teoría (Clase 3) a la Práctica

En la clase anterior aprendimos cómo se estructura una dirección IPv4 (red y host) y cómo la operación lógica AND nos da la dirección de red. En esta sesión, llevaremos esos conocimientos al simulador Cisco Packet Tracer para configurar los parámetros de red en dispositivos finales (PCs, Laptops) y de infraestructura (Routers y Switches).

Recuerda: Para que un dispositivo final se comunique con el mundo exterior, debe tener asignados de forma coherente tres datos fundamentales de la misma red local:
  • Dirección IP: Un identificador único dentro de la subred local (Host ID).
  • Máscara de Subred: Define los límites de la porción de red y host.
  • Puerta de Enlace (Default Gateway): La dirección IP de la interfaz del Router que da salida al exterior (debe estar en el mismo segmento de red).

2. Configuración en Dispositivos Finales (PCs y Laptops)

En Cisco Packet Tracer, configurar la IP de un dispositivo final se realiza de manera gráfica (GUI). Al hacer doble clic en una PC o Laptop, se accede a la pestaña Desktop y luego al módulo de IP Configuration.

Pasos para la Configuración:
  1. Haz doble clic en la PC o Laptop de la topología.
  2. Dirígete a la pestaña superior Desktop.
  3. Haz clic en el icono de IP Configuration.
  4. Selecciona la opción Static (Estático).
  5. Ingresa los datos del esquema de red: la Dirección IP, la Máscara de Subred (se autocompleta la máscara por defecto de su clase, pero puede cambiarse) y la IP del Default Gateway.
Importante: Si el Default Gateway está mal configurado o pertenece a otra subred, la PC no podrá comunicarse con redes externas, aunque sí pueda enviar pings a equipos de su propia subred.

3. Configuración en Routers (Cisco IOS CLI)

El router es el encargado de interconectar las subredes. A diferencia de las PCs, sus puertos (interfaces GigabitEthernet o FastEthernet) vienen apagados de fábrica y no tienen dirección IP configurada. La configuración se realiza preferentemente desde la pestaña CLI (Command Line Interface) utilizando comandos de Cisco IOS.

Comandos de Configuración Paso a Paso:
Comando Modo IOS Explicación
enable Usuario (Router>) Ingresa al modo de ejecución privilegiado.
configure terminal Privilegiado (Router#) Entra al modo de configuración global.
interface g0/0/0 Configuración (Router(config)#) Selecciona la interfaz física específica.
ip address <ip> <mascara> Interfaz (Router(config-if)#) Asigna la dirección IP y la máscara de subred.
no shutdown Interfaz (Router(config-if)#) Activa (enciende) físicamente la interfaz.
exit Interfaz (Router(config-if)#) Regresa al nivel anterior de configuración.

4. Configuración en Switches (Administración Virtual - SVI)

Los switches tradicionales de Capa 2 no necesitan una dirección IP para cumplir su función básica de enviar tramas Ethernet entre puertos. Sin embargo, para poder gestionarlos de forma remota (mediante SSH, Telnet o web) y monitorear su estado, se les debe configurar una Interfaz Virtual de Switch (SVI) (usualmente en la VLAN de administración por defecto, Vlan1).

¿Por qué configurar IP en un Switch?

A diferencia del router, cuyas interfaces físicas necesitan IPs individuales porque cada una es una subred distinta, los puertos de un Switch L2 pertenecen a la misma subred.

Configuramos una IP en la interfaz virtual interface Vlan1 para que el administrador pueda conectarse a él a través de la red local. Además, asignamos el comando ip default-gateway para que el Switch se pueda comunicar y sea administrable desde redes distintas (remotas).

Comandos en Switch:
Switch> enable
Switch# configure terminal
Switch(config)# interface vlan 1
Switch(config-if)# ip address 192.168.10.2 255.255.255.0
Switch(config-if)# no shutdown
Switch(config-if)# exit
Switch(config)# ip default-gateway 192.168.10.1

5. Ejercicio Práctico: Despliegue en Packet Tracer

Imagina que tienes el siguiente esquema en Packet Tracer:

Topología e Instrucciones:

Tienes un Router central R1 que conecta dos departamentos:

  • Subred 1 (Finanzas): Red 192.168.100.0/24 (Máscara 255.255.255.0).
  • Subred 2 (Ingeniería): Red 192.168.200.0/24 (Máscara 255.255.255.0).

El router tiene la interfaz GigabitEthernet0/0/0 conectada a Finanzas, y la interfaz GigabitEthernet0/0/1 conectada a Ingeniería. Aplica la regla de asignar la primera IP útil a las interfaces de gateway del router, y una IP del rango útil para la PC de Finanzas y la PC de Ingeniería.

Tabla de Direccionamiento a Completar:
Dispositivo Interfaz Dirección IP Máscara de Subred Default Gateway
Router R1 G0/0/0 255.255.255.0 N/A
Router R1 G0/0/1 192.168.200.1 255.255.255.0 N/A
PC Finanzas NIC 192.168.100.15 255.255.255.0
PC Ingeniería NIC 255.255.255.0 192.168.200.1
Ayuda de Cálculo
Primera IP Útil

Es la dirección IP inmediatamente siguiente a la Dirección de Red. Por ejemplo, en la red 192.168.100.0, la primera IP útil es la 192.168.100.1.

Default Gateway de la PC

El gateway de una PC siempre debe ser la dirección IP de la interfaz del router a la que está conectado físicamente su segmento de red.

Rangos Válidos

Para la PC de Ingeniería (red 192.168.200.0/24), puedes elegir cualquier IP entre la 192.168.200.2 y la 192.168.200.254 (ya que la .1 la usa el router).

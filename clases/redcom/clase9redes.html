1. Introducción y Arquitectura del Modelo OSI

El Modelo de Interconexión de Sistemas Abiertos (OSI) fue creado en 1984 por la Organización Internacional de Normalización (ISO 7498). En los inicios de las redes informáticas, cada fabricante (IBM, DEC, Apple) utilizaba sus propios protocolos propietarios, impidiendo que equipos de distintos fabricantes se comunicaran entre sí.

Para resolver este problema, la ISO diseñó una arquitectura abstracta modular dividida en 7 capas jerárquicas, donde cada capa presta servicios a la capa superior y solicita servicios a la capa inferior.

Abstracción Modular
Dividir y Conquistar

Si cambia una tecnología en una capa (ejemplo: cambiar de cable UTP a Fibra Óptica en Capa 1), el navegador web (Capa 7) sigue funcionando sin necesidad de modificar una sola línea de código.

2. Las 7 Capas del Modelo OSI: Funciones y Ejemplos Prácticos

Analicemos cada capa comenzando por la más cercana al usuario final (Capa 7) hasta llegar al medio de transmisión físico (Capa 1), usando como hilo conductor la visita a un sitio web (ej. https://www.google.com):

Capa 7: Aplicación PDU: Datos
Función Principal:

Proporciona la interfaz gráfica y los servicios de red directamente a las aplicaciones del usuario (navegadores, clientes de correo, transferencias de archivos).

Protocolos y Dispositivos:

HTTP, HTTPS, FTP, DNS, SMTP, DHCP, SSH. Dispositivos: Gateway de Aplicación, Firewalls de Capa 7 (WAF).

Ejemplo Práctico:

Un usuario escribe www.google.com en Chrome. El navegador genera un mensaje HTTP de solicitud: GET /index.html HTTP/1.1.

Capa 6: Presentación PDU: Datos
Función Principal:

Traduce el formato de datos (codificación ASCII/Unicode), gestiona la compresión de datos y aplica el cifrado/descifrado de seguridad.

Protocolos y Formatos:

SSL/TLS, ASCII, JPEG, PNG, MP4, JSON, XML. Traductor sintáctico de la red.

Ejemplo Práctico:

El mensaje HTTP se cifra mediante TLS 1.3 para proteger contraseñas y se formatean las imágenes en código binario utilizable.

Capa 5: Sesión PDU: Datos
Función Principal:

Establece, administra, sincroniza y finaliza las conexiones (sesiones) entre las aplicaciones en ambos extremos.

Protocolos:

NetBIOS, RPC (Remote Procedure Call), Sockets API, PPTP.

Ejemplo Práctico:

Abre un canal de diálogo persistente y asigna un ID de sesión para garantizar que los paquetes devueltos por el servidor pertenezcan a esa pestaña específica del navegador.

Capa 4: Transporte PDU: Segmento (TCP) / Datagrama (UDP)
Función Principal:

Garantiza la transferencia confiable de datos extremo a extremo. Realiza segmentación, control de flujo (ventana deslizante), control de errores y multiplexación mediante puertos.

Protocolos:

TCP (orientado a conexión, confiable) y UDP (no orientado a conexión, rápido). Números de Puerto (ej. Puerto 80 HTTP, 443 HTTPS).

Ejemplo Práctico:

TCP divide los datos en segmentos, agrega un encabezado con Puerto Origen (ej. 54321) y Puerto Destino (443 HTTPS) y gestiona los ACKs de confirmación.

Capa 3: Red PDU: Paquete
Función Principal:

Responsable del direccionamiento lógico (direcciones IP) y del enrutamiento (Routing) de paquetes a través de múltiples redes interconectadas para encontrar la mejor ruta.

Protocolos y Dispositivos:

IPv4, IPv6, ICMP, ARP, OSPF, BGP. Dispositivos: Routers y Switches Capa 3.

Ejemplo Práctico:

Agrega el encabezado IP con la IP Origen (ej. 192.168.1.50) y la IP Destino del servidor (ej. 142.250.190.46).

Capa 2: Enlace de Datos PDU: Trama (Frame)
Función Principal:

Proporciona direccionamiento físico (dirección MAC), control de acceso al medio (MAC) e inspección de errores mediante secuencia de verificación de trama (FCS/CRC).

Protocolos y Dispositivos:

Ethernet (802.3), Wi-Fi (802.11), PPP, HDLC, VLAN (802.1Q). Dispositivos: Switches (Capa 2) y Bridges.

Ejemplo Práctico:

Encapsula el paquete IP en una Trama Ethernet adicionando la Dirección MAC de origen de tu laptop y la MAC de destino de tu Router Gateway.

Capa 1: Física PDU: Bits
Función Principal:

Transmite la secuencia bruta de bits (0s y 1s) a través de medios físicos (eléctricos, ópticos o radiofrecuencia). Define conectores, voltajes y frecuencias.

Medios y Dispositivos:

Cables UTP (RJ-45), Fibra Óptica, Ondas Wi-Fi (2.4/5GHz). Dispositivos: Hubs, Repetidores, Tarjetas de Red (NIC).

Ejemplo Práctico:

La trama binaria se convierte en pulsos eléctricos de voltaje o fotones de luz que viajan por el cable de red hacia el puerto del Switch.

3. Modelo OSI vs. Modelo TCP/IP

Mientras que el modelo OSI es el **modelo de referencia teórico** estándar utilizado mundialmente para la enseñanza y especificación de arquitecturas, el **Modelo TCP/IP** es la **pila de protocolos real de la Internet comercial**.

1. Física
Resumen de Diferencias Clave:
  • OSI: Modelo conceptual rígido independiente de protocolos específicos. Define claramente la separación de servicios, interfaces y protocolos.
  • TCP/IP: Pila de protocolos práctica creada antes del modelo OSI (desarrollada por el Departamento de Defensa de EE.UU. / ARPANET). Combina las capas superiores en una sola capa de aplicación.

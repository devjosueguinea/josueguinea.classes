Clase 7

División de Subredes de Longitud Fija (FLSM)

Aprende a subdividir un espacio de red en bloques de tamaño idéntico utilizando una máscara de subred constante. Este método clásico es ideal para entornos organizacionales estructurados donde todos los segmentos requieren capacidades de host uniformes.

Objetivos de la Clase
  • Comprender el concepto y el propósito de FLSM (Fixed Length Subnet Mask).
  • Identificar y aplicar las fórmulas matemáticas para el cálculo de subredes y hosts.
  • Determinar la máscara de subred adecuada según la cantidad de subredes o hosts necesarios.
  • Utilizar el simulador interactivo de FLSM para validar diseños de direccionamiento IP estructurado.

1. Introducción y Conceptos Clave

El subneteo clásico o FLSM (Fixed Length Subnet Mask) consiste en dividir una red IP base (habitualmente con máscara por defecto Clase A, B o C) en múltiples subredes secundarias de igual tamaño. En este enfoque, todas las subredes creadas comparten exactamente la misma longitud de máscara de subred y, por lo tanto, admiten el mismo número máximo de hosts.

Enfoque por Subredes
Garantizar Segmentos

Diseñado cuando la prioridad es crear un número específico de subredes independientes (ej. crear 8 departamentos idénticos), sin importar el tamaño de hosts de cada uno.

Enfoque por Hosts
Garantizar Capacidad de Hosts

Diseñado cuando la prioridad es asegurar que cada subred pueda alojar una cantidad fija de equipos (ej. al menos 30 hosts por aula o departamento).

¿Cuándo es ideal FLSM?

FLSM es ideal por su simplicidad en la administración y enrutamiento cuando las necesidades de crecimiento de los diferentes segmentos de red son homogéneas. Sin embargo, genera desperdicio de direcciones si se usa para conectar enlaces WAN que solo requieren 2 hosts.

2. Proceso de Cálculo en Pasos

Para realizar el cálculo de subnetting FLSM, sigue estas fórmulas y pasos:

1
Determinar la cantidad de bits tomados prestados ($s$) o bits de host ($h$)

Dependiendo del criterio de diseño, selecciona la fórmula correspondiente:

Por número de Subredes ($N$):
2s ≥ Subredes Requeridas
Donde $s$ es la cantidad de bits robados a la porción de host original.
Por número de Hosts ($H$):
2h - 2 ≥ Hosts Requeridos
Donde $h$ es la cantidad de bits que deben permanecer en la porción de host.
2
Calcular la Nueva Máscara de Subred

Si calculaste los bits prestados $s$: Nueva Máscara = Máscara Base + s.
Si calculaste los bits de host $h$: Nueva Máscara = 32 - h.

3
Determinar el Tamaño del Bloque (Salto de Red)

El salto entre una subred y la siguiente se calcula elevando 2 a la potencia de los bits de host restantes ($h = 32 - \text{Nueva Máscara}$):

Salto = 2h
4
Listar las Subredes y sus Rangos

Comienza desde la IP de Red Base e incrementa el último octeto (o el octeto correspondiente según la máscara) usando el Tamaño del Bloque:

  • Red IP de la subred: IP de red actual.
  • Primera IP Utilizable: Red IP + 1.
  • Última IP Utilizable: Siguiente Red IP - 2.
  • Broadcast IP: Siguiente Red IP - 1.

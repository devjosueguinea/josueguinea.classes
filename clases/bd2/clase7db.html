1¿Qué es el Aggregation Pipeline?

El Aggregation Pipeline es el motor de procesamiento analítico de MongoDB. En lugar de devolver documentos como están, permite transformarlos, filtrarlos, agruparlos y calcular resultados en una cadena secuencial de etapas (stages). Cada etapa recibe los documentos de la anterior y entrega su resultado a la siguiente, formando un pipeline (tubería de datos).

La sintaxis básica es db.coleccion.aggregate([ etapa1, etapa2, ... ]). El arreglo puede contener cualquier número de etapas; el orden importa.

// Sintaxis general del Aggregation Pipeline db.ventas.aggregate([ { "$match": { "estado": "completada" } }, { "$group": { "_id": "$categoria", "total": { "$sum": "$monto" } } }, { "$sort": { "total": -1 } }, { "$limit": 5 } ]);

2Etapas Fundamentales del Pipeline

$match
Filtrar documentos

Funciona igual que find(): aplica un predicado de filtro y solo deja pasar los documentos que lo cumplen. Conviene ponerlo al inicio del pipeline para reducir el volumen de datos cuanto antes y aprovechar índices.

// Filtrar solo ventas completadas con monto > 500 { "$match": { "estado": "completada", "monto": { "$gt": 500 } } }
$group
Agrupar y acumular

Agrupa los documentos por el campo indicado en _id y calcula acumulaciones usando operadores de agrupamiento:

OperadorDescripciónEquivalente SQL
$sumSuma de valoresSUM()
$avgPromedioAVG()
$minValor mínimoMIN()
$maxValor máximoMAX()
$sum: 1Contar documentosCOUNT()
$pushAcumula valores en arregloGROUP_CONCAT()
$addToSetAcumula valores únicosDISTINCT
// Ventas por categoría: total, promedio y cantidad { "$group": { "_id": "$categoria", "totalVentas": { "$sum": "$monto" }, "promedioMonto": { "$avg": "$monto" }, "numTransacc": { "$sum": 1 } } }
$project
Proyectar y transformar campos

Selecciona qué campos incluir (1) o excluir (0) en la salida. También permite renombrar campos, crear campos calculados y aplicar expresiones.

// Mostrar solo categoría y total; calcular con IVA (12%) { "$project": { "_id": 0, "categoria": "$_id", "total": 1, "conIVA": { "$multiply": [ "$total", 1.12 ] } } }
$sort
Ordenar resultados

Ordena los documentos por uno o más campos. 1 = ascendente, -1 = descendente. Equivale al ORDER BY de SQL.

// Ordenar por totalVentas de mayor a menor { "$sort": { "totalVentas": -1 } }
$limit
Limitar cantidad de documentos

Devuelve solo los primeros N documentos. Combinado con $sort forma el patrón "Top-N". Equivale a LIMIT N en SQL.

// Solo los 3 primeros resultados { "$limit": 3 }
$unwind
Descomponer arreglos

Toma un campo que contiene un arreglo y genera un documento separado por cada elemento del arreglo. Es fundamental antes de aplicar $group sobre un campo de tipo arreglo.

// Un documento con tags:["a","b"] genera 2 documentos independientes { "$unwind": "$tags" }
$lookup
Unir colecciones (JOIN)

Realiza un left outer join entre la colección actual y otra colección de la misma base de datos. Es el equivalente al JOIN de SQL dentro del pipeline.

// Enriquecer ventas con datos de la colección "clientes" { "$lookup": { "from": "clientes", "localField": "clienteId", "foreignField": "_id", "as": "datosCliente" } }

3Ejemplos de Pipelines Completos

Ejemplo 1: Ventas totales por categoría (ordenadas descendente)

Objetivo: obtener la suma de montos agrupada por categoría, solo de ventas completadas, ordenada de mayor a menor.

db.ventas.aggregate([ // 1. Solo ventas completadas { "$match": { "estado": "completada" } }, // 2. Agrupar por categoría y sumar montos { "$group": { "_id": "$categoria", "totalVentas": { "$sum": "$monto" }, "numOrdenes": { "$sum": 1 } }}, // 3. Renombrar _id a categoria { "$project": { "_id": 0, "categoria": "$_id", "totalVentas": 1, "numOrdenes": 1 }}, // 4. Ordenar de mayor a menor { "$sort": { "totalVentas": -1 } } ]);
Ejemplo 2: Top 3 vendedores del mes

Objetivo: encontrar los 3 vendedores con mayor monto acumulado en julio 2024.

db.ventas.aggregate([ { "$match": { "mes": 7, "anio": 2024 } }, { "$group": { "_id": "$vendedor", "totalVendido": { "$sum": "$monto" } }}, { "$sort": { "totalVendido": -1 } }, { "$limit": 3 }, { "$project":{ "_id": 0, "vendedor": "$_id", "totalVendido": 1 }} ]);
Ejemplo 3: Frecuencia de etiquetas con $unwind

Objetivo: expandir el arreglo tags y contar la frecuencia de cada etiqueta.

db.productos.aggregate([ { "$unwind": "$tags" }, { "$group": { "_id": "$tags", "frecuencia": { "$sum": 1 } }}, { "$sort": { "frecuencia": -1 } } ]);

5Ejercicios Propuestos

Los siguientes ejercicios están diseñados para que los alumnos construyan sus propios pipelines. Puedes intentar resolverlos en el simulador antes de ver la respuesta sugerida.

1
Monto promedio por vendedor

Usando la colección ventas del simulador, construye un pipeline que calcule el monto promedio de ventas por cada vendedor, ordenado de mayor a menor promedio. El resultado final debe mostrar solo los campos vendedor y promedioMonto (sin el campo _id).

Etapas sugeridas: $group → $project → $sort

2
Resumen de ventas completadas por categoría

Filtra solo las ventas con estado "completada" y luego calcula por cada categoría: la suma total de montos (totalMonto), el número de transacciones (numTransacciones) y el monto máximo de una sola venta (montoMax). Ordena los resultados por totalMonto descendente.

Etapas sugeridas: $match → $group → $sort

3
Frecuencia de etiquetas (tags) con $unwind

La colección ventas tiene un campo tags que es un arreglo. Construye un pipeline que: (a) descomponga el arreglo con $unwind, (b) agrupe por cada etiqueta y cuente su frecuencia, y (c) muestre solo las etiquetas con frecuencia ≥ 2 usando una segunda etapa $match después del $group. Ordena el resultado por frecuencia de mayor a menor.

Etapas sugeridas: $unwind → $group → $match → $sort

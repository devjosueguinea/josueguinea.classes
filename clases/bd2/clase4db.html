Operaciones de escritura, actualizacion y eliminacion

En esta clase dominaras el CRUD completo de MongoDB: Create (insertar), Read (consultar), Update (actualizar) y Delete (eliminar). Conoceras los metodos esenciales, los operadores de actualizacion y las estrategias de borrado seguro.

1. Que es el CRUD?

CRUD es el acronimo de las cuatro operaciones fundamentales que toda base de datos debe soportar. En MongoDB, cada operacion se mapea directamente a metodos del shell (mongosh) o a drivers de lenguaje como Node.js, Python, Java, etc.

Modifica campos de documentos que ya existen.

Borra documentos de manera selectiva o masiva.

2. Insercion de Documentos (CREATE)

MongoDB ofrece dos metodos principales para insertar documentos. Si la coleccion no existe, MongoDB la crea automaticamente al insertar el primer documento.

insertOne()

Inserta un unico documento. Retorna un objeto con el _id generado automaticamente.

db.empleados.insertOne({ nombre: "Ana Garcia", departamento: "Tecnologia", salario: 1800, fechaIngreso: new Date("2024-03-15"), activo: true })

Resultado: { acknowledged: true, insertedId: ObjectId("...") }

insertMany()

Inserta un arreglo de documentos en una sola operacion atomica. Mas eficiente que multiples insertOne().

db.empleados.insertMany([ { nombre: "Carlos Lopez", departamento: "Ventas", salario: 1200 }, { nombre: "Maria Rodriguez", departamento: "RRHH", salario: 1400 }, { nombre: "Pedro Martinez", departamento: "Tecnologia", salario: 2100 } ])

Resultado: { acknowledged: true, insertedCount: 3 }

El campo _id

Si no proporcionas un _id, MongoDB genera un ObjectId unico de 12 bytes. Puedes usar tu propio _id (numero, cadena, etc.) pero debe ser unico en la coleccion.

Orden de insercion

Por defecto, insertMany() inserta en orden. Si un documento falla (p.ej. _id duplicado), los anteriores no se revierten. Usa { ordered: false } para continuar con el resto ante errores.

3. Actualizacion de Documentos (UPDATE)

Las operaciones de actualizacion se componen de un filtro (que documentos afectar) y un documento de actualizacion (que cambiar). Los operadores de actualizacion determinan como se modifican los campos.

Operadores de Actualizacion mas comunes
OperadorDescripcionEjemplo
$set Establece el valor de un campo. Si no existe, lo crea. { $set: { salario: 2000 } }
$unset Elimina un campo del documento. { $unset: { temporal: "" } }
$inc Incrementa (o decrementa con valor negativo) el valor numerico del campo. { $inc: { stock: -3 } }
$rename Renombra un campo del documento. { $rename: { "apellido": "primerApellido" } }
$push Agrega un elemento al final de un array. { $push: { tags: "oferta" } }
$pull Elimina elementos de un array que coincidan con la condicion. { $pull: { tags: "inactivo" } }
$addToSet Agrega a un array solo si el elemento no existe (evita duplicados). { $addToSet: { roles: "admin" } }
updateOne(filtro, actualizacion)

Modifica el primer documento que coincida con el filtro.

db.empleados.updateOne( { nombre: "Ana Garcia" }, { $set: { salario: 2100 }, $inc: { aniosExperiencia: 1 } } )

Resultado: { matchedCount: 1, modifiedCount: 1 }

updateMany(filtro, actualizacion)

Modifica todos los documentos que coincidan con el filtro.

db.empleados.updateMany( { departamento: "Ventas" }, { $set: { activo: false } } )

Resultado: { matchedCount: 3, modifiedCount: 3 }

Opcion Upsert

Con { upsert: true }, si no hay coincidencia MongoDB inserta un nuevo documento combinando el filtro con los cambios. Ideal para el patron "crear si no existe".

db.configuracion.updateOne( { clave: "tema_global" }, { $set: { valor: "dark", actualizadoEn: new Date() } }, { upsert: true } // Crea el documento si no existe )

4. Eliminacion de Documentos (DELETE)

Las operaciones de eliminacion en MongoDB son permanentes e irreversibles. Siempre es buena practica ejecutar primero un find() con el mismo filtro para verificar que documentos se veran afectados antes de borrar.

deleteOne(filtro)

Elimina el primer documento que coincida con el filtro.

db.empleados.deleteOne({ nombre: "Carlos Lopez" })

Resultado: { acknowledged: true, deletedCount: 1 }

deleteMany(filtro)

Elimina todos los documentos que coincidan. Con filtro {} vacia la coleccion entera.

db.empleados.deleteMany({ activo: false })

Resultado: { acknowledged: true, deletedCount: 5 }

drop() vs deleteMany({})

deleteMany({}) elimina todos los documentos pero conserva la coleccion e indices.
db.coleccion.drop() elimina la coleccion completamente junto con todos sus indices.

Borrado seguro (best practice)

Antes de ejecutar deleteMany(), valida con: db.col.find(filtro).count()
Considera el "soft delete": agrega eliminado: true en lugar de borrar fisicamente el documento.
